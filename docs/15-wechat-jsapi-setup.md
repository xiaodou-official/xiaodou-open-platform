# 微信 JSAPI 公众号配置（商户自有收银台）

> docId：`XD-OP-15` ｜ version：`1.0.0` ｜ status：`PUBLISHED`

这一篇只讲一件事：**新渠道商户要收微信，必须把自己的公众号配好，并把 appid 绑定到自己的商户号**。

配置分两半：**微信侧**（公众号后台、微信支付商户平台）和**平台侧**（商家后台的「商户收银台」页）。
平台只能登记与读回，**不能代你在微信侧配置**。

> 如果买家只在平台收银页付款，商户单的微信不可用（平台服务号 appid 不属于你的商户号）——
> 那条路请用支付宝，或把买家引导到你自己域名下的收银页。支付宝**不需要**公众号 appid，也不需要授权目录。

## 1. 先判断你需要哪条路

| 你的情况 | 微信收款怎么走 |
| --- | --- |
| 买家在**你自己的页面/公众号**里付款 | 按本篇配置公众号 + 绑定 appid，页面调起 JSAPI |
| 买家在**平台收银页**付款 | 商户单微信不可用；用支付宝，或改走自有收银页 |
| 只收支付宝 | 不需要本页任何配置 |

**平台服务号/平台公众号的 appid 不能用于商户单**；一条微信支付配置只对应一个公众号 appid。

## 2. 前置条件（缺一不可）

- 一个**已通过微信认证的服务号**（订阅号没有网页授权能力）；
- 该公众号已具备微信支付能力；你的商户号已完成实名与微信渠道开通；
- 一个**已 ICP 备案**的 HTTPS 域名（收银页与 OAuth 回跳都在它下面）；
- 你的服务端能安全保存公众号 `AppSecret`，并能完成一次网页授权换取 `openid`。

## 3. 微信侧配置（三步）

### 3.1 公众号后台：配置网页授权域名

路径：公众号后台 → 设置与开发 → 公众号设置 → 功能设置 → **网页授权域名**。

- 填**纯域名**（不带 `https://`、不带路径），例如 `pay.example.com`；
- 按微信要求把校验文件放到该域名根目录，通过校验；
- 之后 OAuth 的 `redirect_uri` 必须落在这个域名下。

> 只调起支付不需要 JS-SDK；如果你另外用 JS-SDK（分享、拍照等），才需要再配 **JS 接口安全域名**。

### 3.2 微信支付商户平台：配置 JSAPI 支付授权目录

路径：微信支付商户平台 → 产品中心 → 开发配置 → **支付授权目录**（名称以微信后台为准）。

- 目录必须是 **HTTPS**，最多 **5 个**；
- 要覆盖**发起支付的那个页面**（页面 URL 必须落在某个已配置目录下）；
- 目录与页面要**逐级匹配**——多一层、少一层都不行；
- 如果你的商户号由服务商代管、没有登录权限，请联系对接人协助配置。

> 支付授权目录**不在平台 API 的配置范围内**：平台只登记你在本页填写的目录并读回状态，不能替你修改。

### 3.3 确认 appid 与商户号的归属

- 公众号 appid 形如 `wx` + 16 位十六进制；
- 它必须是**你自己的**公众号，且要绑定到**你自己的商户号**；
- 绑定动作在平台侧完成（下一节），不要在微信侧另找入口重复绑定。

## 4. 平台侧：绑定 appid

路径：**商家后台 → 商户收银台**。

| 字段 | 填什么 |
| --- | --- |
| 公众号 appid | 你自己的公众号 appid |
| 支付授权域名 | 收银页所在域名（只填域名，不带 `https://`） |
| 网页授权域名 | 公众号后台配置的网页授权域名；与支付域名相同可留空 |
| JSAPI 支付授权目录 | 与微信支付商户平台里配置的目录**逐字一致**，每行一个，`https://` 开头，最多 5 个 |
| 首次绑定联系人 | 姓名、手机号、邮箱（渠道备案用，不展示给买家） |

提交后**以渠道读回为准**：页面显示「appid 已绑定」才算完成；未确认前微信支付不可用
（建单返回 `403`，原因 `APPID_NOT_BOUND` 或 `OPEN_API_MERCHANT_APPID_UNAVAILABLE`）。
更新 appid 或目录后同样要等读回确认。

## 5. 服务端：取 openid → 建单 → 拉起

### 5.1 取 openid（网页授权）

买家在微信内打开你的收银页时，先做一次静默授权（`scope=snsapi_base`）：

```text
https://open.weixin.qq.com/connect/oauth2/authorize
  ?appid=<你的公众号 appid>
  &redirect_uri=<URL 编码后的回跳地址，必须在网页授权域名下>
  &response_type=code
  &scope=snsapi_base
  &state=<你的防重放随机串>
#wechat_redirect
```

用 `code` 换 `access_token` 与 `openid`。**openid 是公众号维度的**：同一个买家在不同公众号下
openid 不同，必须是**你这个 appid 下**的 openid。

### 5.2 建单

- 开放平台接口：`POST /api/open/v1/payments`，`channel` 用微信，另传 `subOpenid`（必填）、
  `subAppid`（可选，传了必须与你绑定的 appid 逐字一致）；
- 商户自有收银台接口：`POST /api/merchant/v1/payments`，`channel=WECHAT`，另传 `subOpenid`。

`subOpenid` **不落库**：同一单需要重新拉起时必须重新提交。

### 5.3 拉起支付

响应里的 `jsapiParams`（`appId/timeStamp/nonceStr/package/signType/paySign`）在你的页面直接调起：

```js
function onBridgeReady() {
  WeixinJSBridge.invoke('getBrandWCPayRequest', jsapiParams, function (res) {
    // res.err_msg 只是前端回调，不是支付终态
  });
}
if (typeof WeixinJSBridge === 'undefined') {
  document.addEventListener('WeixinJSBridgeReady', onBridgeReady, false);
} else {
  onBridgeReady();
}
```

**支付成功的唯一判据**：查单结果，或验过签的事件通知。`getBrandWCPayRequest` 的回调、
页面跳转、「已完成支付」按钮都不算终态。

## 6. 排障

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 打开页面提示 `redirect_uri` 参数错误 | 网页授权域名未配置，或回跳地址不在该域名下 | 回公众号后台补配；回跳地址必须在该域名下 |
| 调起支付提示「当前页面的URL未注册」 | 支付授权目录没有覆盖当前页面 | 在微信支付商户平台补目录；核对层级与结尾 |
| 支付报 appid 与 openid 不匹配 | openid 不是你这个公众号下的 | 用同一个 appid 重新授权取 openid |
| 建单 `403`，原因 `APPID_NOT_BOUND` / `OPEN_API_MERCHANT_APPID_UNAVAILABLE` | 平台侧未绑定，或读回未确认 | 在「商户收银台」提交并等读回；仍未生效联系对接人 |
| 建单 `422`，原因 `APPID_MISMATCH` / `OPEN_API_MERCHANT_APPID_INVALID` | 用了平台 appid，或 `subAppid` 与绑定值不一致 | 改成你自己的 appid，并与绑定值逐字一致 |
| 微信外手机浏览器打不开支付 | 微信支付只能在微信内调起 | 引导买家在微信内打开，或改走支付宝 |
| 支付宝正常、微信不可用 | 微信侧配置未完成 | 按本篇逐项核对 |

## 7. 边界

- 平台**不代做**公众号认证、网页授权域名与支付授权目录配置；平台只登记与读回。
- 平台服务号/平台公众号的 appid **永不**用于你的商户单。
- 微信内**不能**直接拉起支付宝；微信内收款只能走本篇的 JSAPI。
- 公众号与商户号的关联/授权是否需要在微信侧再确认，以微信后台实际提示为准；绑定结果以平台读回为准。
- 本篇不改变平台收银页的行为；平台收银页商户单的微信仍不可用。
