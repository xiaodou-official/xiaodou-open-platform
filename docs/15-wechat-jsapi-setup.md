# 微信支付开通与拉起（平台统一配置）

> docId：`XD-OP-15` ｜ version：`2.4.0` ｜ status：`PUBLISHED`

这一篇只讲一件事：**新渠道商户的微信收款由平台统一配置，商户不需要绑定自己的公众号 appid，
也不需要填写授权目录。**

平台侧完成的是「公众号 appid + 支付授权目录」的配置与读回；商户侧只需要完成自己的经营前置，
然后二选一：

- **平台桥接（推荐，2026-11-07 起）**：建单**不传** `subOpenid`，把响应里的 `payUrl`
  交给买家。买家在微信内打开后，由平台在**平台域收银页**内完成服务号 OAuth 与
  JSAPI 拉起——商户不需要公众号后台权限，也不受「支付授权目录」限制。
- **商户自管**：商户自己拿到买家在平台公众号下的 `subOpenid` 并在建单/重拉起时提交，
  响应返回 `jsapiParams` 由商户页面 `WeixinJSBridge` 拉起。

> 买家在**平台收银页**付款时不涉及本节；本节面向**自建页面/自有收银流程**的商户。

## 1. 谁能开通（门户手动申请，服务端自动审批）

> **2026-11-09 起（新商户）**：微信渠道**首次开通**本身必须**同时**满足
> 「连续 7 个自然日每天至少 1 笔成功交易」与「保证金净额 ≥¥168」；只缴 ¥168
> **不能**提前开。已开微信渠道的商户不受影响，下表「快速通道」继续适用于
> 平台 appid 绑定。微信渠道开通与微信实名只在**北京时间 08:00–18:00** 开放，
> 其余时间入口关闭（状态刷新不受影响）。

| 前置 | 说明 |
| --- | --- |
| 商户认证与微信渠道开通 | 进件审核通过；微信渠道已开通且实名通过（新商户首次开通需先满足 7 天＋168 与时间窗） |
| 保证金 | 按平台规则应缴并已实缴（无需缴纳的商户视为已满足）；金额由系统自动计算，可随时主动缴纳 |
| 正常经营观察 | **连续 7 个自然日每天至少 1 笔成功交易**（任一收款渠道，不限于支付宝）；今日必须有成功交易 |
| 快速通道 / 平台例外 | **已开微信渠道的商户**：保证金净额 ≥¥168 可免 7 天观察；应缴高于 ¥168 时可自愿补缴/缴清应缴（不强制缴清），门户可主动缴纳；平台运营也可按商户号人工开通 |

满足条件后，商户在门户「收款信息 → 收款开通」点**「立即开通」**即可：服务端现场校验，
达标立即自动审批通过并完成平台侧配置，**不需要填表、不需要提供 appid/密钥/授权目录**。
**支付宝认证通过后自动开通，无需申请**；微信认证通过后仍需手动点一次「立即开通」。

> 微信认证通过但尚未达标时，门户会显示缺什么（缴保证金 / 连续 7 天成交进度），
> 完成后再点「立即开通」即可，不需要联系运营。新商户若微信渠道尚未开成，
> 门户会直接显示微信开通条件与时间窗，不会先开通渠道再等待。

## 2. 平台做了什么

1. 在收款服务商侧为该商户登记平台的公众号 appid 与支付授权目录；
2. 读回确认配置对该商户生效（未读回成功前不会显示「已开通」）；
3. 建单时使用平台公众号 appid 作为 `subAppid`，买家在该公众号下完成支付。

商户**不要**在微信侧另行绑定自己的公众号 appid，也不要在请求里传自己的 appid——
平台公众号 appid 之外的 appid 会被拒绝。

## 3. 拉起支付

### 3.1 平台桥接（不传 `subOpenid`）

建单/重拉起**不传** `subOpenid` 即为桥接模式：

- 下单只落库（订单 `CREATED` + 待派发尝试），**零当次渠道外呼**；
- 响应 `payUrl` 指向平台收银页（`payUrl` 是唯一入口，不要把域名写死在客户端），
  `jsapiParams` 不下发；
- 买家在微信内打开该链接：页面自动完成服务号 OAuth → 服务端用**商户自己的收款主体**
  代发微信 JSAPI 支付 → `WeixinJSBridge` 拉起；桌面/微信外按页面引导（扫码或复制链接进微信）；
- 支付完成后按订单冻结的 `returnUrl` 回跳；终态仍以查单/验签事件通知为准。

适用条件由服务端判定（不满足时收银页给中性提示，不会把渠道错误暴露给买家）：商户直连
通道已开通、商户已完成平台公众号配置读回（`platformAppidBound=true`）、订单为商户
微信单且渠道可用。**商户自有公众号 appid 的订单不能走桥接**（授权目录只覆盖平台域），
必须用 3.2 的自管形态。

### 3.2 商户自管（提交 `subOpenid`）

`subOpenid` 是买家在**平台公众号**下的 openid。商户若自行完成网页授权，可按此形态提交；
openid 是公众号维度的，其他公众号下的 openid 不能用于本平台商户单。

- 开放平台接口：`POST /api/open/v1/payments`，`channel` 用微信，传 `subOpenid`（可选）；
  `subAppid` 可选，如传必须等于平台公众号 appid；
- 商户直连接口：`POST /api/merchant/v1/payments`，`channel=WECHAT`，传 `subOpenid`。

`subOpenid` **不落库**：同一单需要重新拉起时必须重新提交（或改用桥接形态重拉起）。

### 3.3 调起（仅自管形态）

响应里的 `jsapiParams`（`appId/timeStamp/nonceStr/package/signType/paySign`）在页面直接调起：

```js
function onBridgeReady() {
  WeixinJSBridge.invoke('getBrandWCPayRequest', jsapiParams, function (res) {
    // res.err_msg 只是前端回调，不是支付终态
  });
}
if (typeof WeixinJSBridge === 'undefined') {
  document.addEventListener('WeixinJSBridgeReady', onBridgeReady, false);
} else {
  onBridgeReady();
}
```

**支付成功的唯一判据**：查单结果，或验过签的事件通知。`getBrandWCPayRequest` 的回调、
页面跳转、「已完成支付」按钮都不算终态。

### 3.4 重复点击

支付拉起期间请锁定按钮，直到桥回调（成功/取消/失败）或超时后再解锁；
平台对同一订单的并发建单会复用同一个活动支付尝试，重复点击不会产生重复的渠道订单。

## 4. 开通后自测（建议）

1. 下载最新 **Skill 与文档包**（平台官网「文档与 Skill 下载」页，核对版本号与 SHA-256）；
2. 在平台交易 / 开放平台 / 易支付任一入口创建一笔 **¥0.01 微信支付**订单，确认：
   - 买家在微信内能正常拉起支付；
   - 订单收款主体是**你自己的商户号**（不是平台服务商号）；
   - 支付成功后查单/通知为成功终态；
3. 发起一笔 **¥0.01 退款**，确认退款成功、金额与手续费按原单快照回吐；
4. 若任一步失败，保留订单号/时间/截图，联系平台对接人；不要重复创建多笔测试单。

## 5. 排障

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 门户显示「待缴保证金」 | 保证金未足额实缴 | 按门户提示缴纳（金额系统自动计算，可随时主动缴纳）；缴清后回到门户点「立即开通」 |
| 门户显示「观察期」 | 连续 7 天成功交易天数未满足 | 正常经营即可；满足后回到门户点「立即开通」 |
| 门户显示「待开通」 | 微信认证已通过，尚未点击开通 | 点「立即开通」，服务端自动审核 |
| 门户显示「配置中 / 渠道审核中」 | 平台正在配置或等待渠道生效 | 无需操作，状态会自动刷新 |
| 建单返回 `APPID_NOT_BOUND` / `OPEN_API_MERCHANT_APPID_UNAVAILABLE` | 平台配置尚未读回生效 | 等待门户状态变为「已开通」；持续失败联系对接人 |
| 建单返回 `APPID_MISMATCH` / `OPEN_API_MERCHANT_APPID_INVALID` | 传了非平台的 appid | 改为平台公众号 appid，或省略 `subAppid` |
| 调起支付提示「当前页面的URL未注册」 | 支付授权目录未覆盖当前页面 | 联系对接人核对平台授权目录 |
| 微信外手机浏览器打不开支付 | 微信支付只能在微信内调起 | 引导买家在微信内打开，或改走支付宝 |

## 6. 边界

- 平台**不提供**商户自有公众号的自助绑定；商户自有公众号/自有 appid 的配置方式已退役。
- 平台公众号 appid 之外的 appid 一律不能用于本平台商户单。
- 微信内**不能**直接拉起支付宝；微信内收款只能走本篇的 JSAPI。
- 本篇不改变平台收银页的行为。
