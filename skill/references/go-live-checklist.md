# 上线检查清单（可逐条自检）

> 人读版：`docs/11-go-live-checklist.md`（**不在本 Skill 包内**：Skill 包只含 `skill/**` 与 `examples/**`，需要时从门户「文档下载」包或公开仓的 `docs/` 取）。
> 平台**不提供沙箱/测试应用/回调模拟器**；上线前必须逐条自检，全部打勾再接真实流量。

## 凭证与签名

- [ ] 用固定输入算出的**规范串**与参考实现逐字节一致（golden 向量见 `signature-spec.md` 第 4 节）。
- [ ] 路径解码一次、query 按键名排序并 RFC3986 重编码、`Content-Type` 小写去参、body 哈希取原始字节；**响应验签侧同样归一化**，且只对带 `X-XD-Response-*` 四头的响应强制验签。
- [ ] 私钥只在服务端/密钥服务；浏览器、仓库、日志里都没有。
- [ ] 服务器 NTP 对时；每次请求 nonce 唯一。
- [ ] 对平台响应做 `XD-Response-v1` 验签，公钥来自固定文档页/门户；**按 `kid` 存进你方配置**（不是每次现取）。
- [ ] 落地时**本地算一遍平台公钥指纹**，与公示指纹逐字符比对——这一步能挡住「换了公钥没换指纹」的半更新。

## 下单与幂等

- [ ] 重试复用**同一个 `requestId` 与同一份请求体**、**换新 nonce**（代码级保证）。
- [ ] 所有 `POST` 都带 `Content-Type: application/json`（含无请求体的重拉起/关单）。
- [ ] `outTradeNo` 稳定，重试不换号。
- [ ] `409` 的处理是**先查单**（写在错误处理代码里）。
- [ ] 请求体无 schema 外字段；`tradeScope` 按申报正确传参。

## 收款材料与终端

- [ ] `payUrl`/`qrCode` 用响应原值，不拼装、不转发第三方。
- [ ] 渲染 `qrCode` 前做前缀防呆复检；非法值不渲染、不报错、不打印。
- [ ] 代码里没有「拿旧码长期展示」的分支（查询接口恒空，新码走重拉起）。
- [ ] 自有 App 用系统浏览器打开收银链，无 WebView 内嵌路径。
- [ ] PC / 手机微信外 / 手机微信内三种形态都自测过（可用 `demo/h5-cashier/preview.html`）。
- [ ] 微信外若复述引导文案，与逐字文案一致。

## 终态与事件

- [ ] 全库搜过：没有把「回跳/页面状态/用户点击」当支付成功的地方。
- [ ] 事件用**原始字节**验签；验签失败不落账。
- [ ] `eventId` 建唯一索引，重复投递丢弃但仍回 `success`。
- [ ] 成功时返回 2xx 且 body 字节正好是 `success`。
- [ ] 用 `stateVersion`/状态机处理乱序。
- [ ] 有查单补偿任务。
- [ ] 订单/退款 `UNKNOWN` 时不重新下单、不重发退款、不报失败。
- [ ] `notifyUrl` 是 HTTPS、公网可达、能承受重复投递。

## 退款与对账

- [ ] `outRefundNo` 稳定；`UNKNOWN` 不换号重试。
- [ ] 本地校验「累计退款 ≤ 实付」。
- [ ] 入账用每单 `feeProjection`（含 `ruleVersion`），代码里没有硬编码费率表。
- [ ] 有日对账任务，覆盖「平台成功/我未成功」「我成功/平台未成功」「金额不一致」。

## 安全与运维

- [ ] 生产出口 IP（含灾备）已在门户白名单。
- [ ] 日志无私钥、无签名材料、无完整请求体、无买家 PII。
- [ ] 承载收款材料的页面不引第三方 CDN/统计/字体，不把材料地址写进浏览器存储。
- [ ] `returnUrl` 不带交付内容与 token。
- [ ] `429`/`503` 指数退避；`422` 不重试。
- [ ] 对 401/403/502 与事件投递失败率配告警。

## 上线动作

- [ ] **申报的每个网站域名都完成了归属验证**（DNS TXT 或回源文件二选一）；**新增或更换域名要重新申报并验证**——下单本身不校验域名，但**回调地址必须落在已验证域名下**，否则 `notifyUrl` 提交会被拒。
- [ ] `notifyUrl` 与出口 IP 白名单就位（两者任一不齐，首单一定失败）。
- [ ] 安排真实小额首单，明确盯的人与指标（订单状态、事件到达、结算视图）。
- [ ] 需要协助时通过官网反馈渠道提交首单计划（不承诺 SLA）。
- [ ] 明确「关掉下单入口」的开关与话术（不要靠改代码紧急止血）。
- [ ] 留档：golden 向量、事件验签测试结果、终端自测记录。
