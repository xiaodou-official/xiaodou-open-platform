# 微信支付开通与拉起（平台统一配置）

> 人读版：`docs/15-wechat-jsapi-setup.md`（**不在本 Skill 包内**：Skill 包只含 `skill/**` 与 `examples/**`，需要时从门户「开发者文档」页的「下载文档包」或公开仓的 `docs/` 取）。

这篇只解决一件事：**新渠道商户收微信时，平台怎么配置、商户怎么拉起**。
公众号 appid 与支付授权目录由平台统一配置并读回，**商户不需要绑定自己的公众号 appid**。

## 1. 适用判断

```text
买家在哪付款？
├─ 商户自己的页面 / 公众号内 → 用本篇（微信 JSAPI）
├─ 平台收银页 → 不涉及公众号配置
└─ 只收支付宝 → 不需要公众号 appid，也不需要授权目录
```

铁律：

- 平台公众号 appid 是唯一可用的 appid；**商户自有公众号 appid 不能用于本平台商户单**。
- 商户**不要**在微信侧另行绑定 appid，也不要在请求里传自己的 appid。
- 支付宝没有逐商户 appid，与微信 JSAPI 是同一个建单接口的两个 `channel`。
- 微信支付只能在微信内调起；微信外手机浏览器与自有 App 内没有直接拉起形态。

## 2. 开通前置（门户手动「立即开通」，服务端自动审批）

> **2026-11-09 起（新商户）**：微信渠道**首次开通**必须**同时**满足
> 「连续 7 个自然日每天至少 1 笔成功交易」与「保证金净额 ≥¥168」；只缴 ¥168
> **不能**提前开。已开微信渠道的商户不受影响。微信渠道开通与微信实名只在
> **北京时间 08:00–18:00** 开放，其余时间入口关闭（状态刷新不受影响）。

- 进件审核通过，微信渠道已开通且实名通过（新商户首次开通需先满足 7 天＋168 与时间窗）；
- 按平台规则应缴的保证金已实缴（无需缴纳视为已满足）；金额系统自动计算，可随时主动缴纳；
- **连续 7 个自然日每天至少 1 笔成功交易**（任一收款渠道，不限于支付宝；今日必须有成功），
  **已开微信渠道的商户**才适用「或保证金净额 ≥¥168 免 7 天观察」；应缴高于 ¥168 时
  可自愿补缴/缴清应缴（不强制缴清），或平台运营例外开通；门户可主动缴纳；
- 平台配置已读回生效（门户「收款信息 → 收款开通」显示「已开通」）。

支付宝认证通过后**自动开通**，无需申请；微信认证通过后仍需在门户点一次**「立即开通」**。
服务端现场校验，达标立即自动审批通过。商户不需要提交 appid、域名或授权目录，
也不需要联系运营申请。微信认证通过但未达标时，门户会显示缺什么（保证金 / 7 天进度），
完成后回来点「立即开通」即可。

### 2.1 开通后自测

1. 下载最新 Skill 与文档包（平台官网「文档与 Skill 下载」页，核对版本号与 SHA-256）；
2. 在平台交易 / 开放平台 / 易支付任一入口创建一笔 **¥0.01 微信支付**订单，确认
   收款主体是自己的商户号、支付成功、查单/通知为成功终态；
3. 发起一笔 **¥0.01 退款**，确认按原单快照回吐；
4. 失败时保留订单号/时间/截图联系对接人，不要重复创建测试单。

## 3. 拉起支付

### 3.1 平台桥接（不传 `subOpenid`，推荐）

建单/重拉起**不传** `subOpenid`：下单只落库、零当次外呼，响应 `payUrl` 指向平台
收银页；买家在微信内打开后由平台完成服务号 OAuth 与 JSAPI 拉起。商户不需要公众号
后台权限，也不受支付授权目录限制。**商户自有公众号 appid 的订单不能走桥接**。

### 3.2 商户自管（提交 `subOpenid`）

`subOpenid` 是买家在**平台公众号**下的 openid，通过平台提供的网页授权入口获取。
其他公众号下的 openid 不能用于本平台商户单。

- `POST /api/open/v1/payments`，`channel` 用微信，传 `subOpenid`（可选）；
  `subAppid` 可选，如传必须等于平台公众号 appid；
- 商户直连：`POST /api/merchant/v1/payments`，`channel=WECHAT`，传 `subOpenid`。

`subOpenid` **不落库**：同一单重新拉起必须重新提交（或改用桥接形态）。

### 3.3 调起与终态

- 用响应里的 `jsapiParams` 调 `WeixinJSBridge.invoke('getBrandWCPayRequest', ...)`；
- 支付拉起期间锁定按钮，直到桥回调（成功/取消/失败）或超时后再解锁；
  重复点击会复用同一个活动支付尝试，不会产生重复渠道订单；
- **终态只认查单或验签后的事件通知**；前端回调、页面跳转、「已完成支付」按钮都不算。

## 4. 排障

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 门户显示「待缴保证金/观察期」 | 前置未满足 | 按门户提示完成；达标后回门户点「立即开通」 |
| 门户显示「待开通」 | 微信认证已通过但未点击 | 点「立即开通」，服务端自动审核 |
| 门户显示「配置中/渠道审核中」 | 配置尚未读回生效 | 等待自动刷新，无需操作 |
| `APPID_NOT_BOUND` / `OPEN_API_MERCHANT_APPID_UNAVAILABLE` | 平台配置未读回生效 | 等门户变为「已开通」；持续失败联系对接人 |
| `APPID_MISMATCH` / `OPEN_API_MERCHANT_APPID_INVALID` | 传了非平台 appid | 改为平台公众号 appid，或省略 `subAppid` |
| 「当前页面的URL未注册」 | 授权目录未覆盖当前页面 | 联系对接人核对平台授权目录 |
| 微信外打不开支付 | 微信支付只能在微信内调起 | 引导微信内打开，或改走支付宝 |

## 5. 边界

- 商户自有公众号的自助绑定已退役；平台不提供该形态。
- 平台公众号 appid 之外的 appid 一律拒绝。
- 微信内不能直接拉起支付宝。
