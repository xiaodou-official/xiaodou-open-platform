# v1.0.0 变更公告

## 一句话

商家现在可以**在自己页面上渲染官方收款码**；买家在**手机浏览器**上打开收银页，点一下**手势主按钮**即打开支付宝（兜底：长按识别 / 截屏后用相册扫码），微信内打开则**零点击**直接拉起支付面板。

## 新增

1. **支付宝官方收款码可下发**：下单响应新增 `qrCode` 字段，商家可在自有 PC 页面直接渲染二维码完成扫码支付。
   - 仅支付宝渠道、服务端校验通过后才下发；**只在下发响应有效**，查询接口恒为 `null`，需要新码走**重拉起**（新尝试=新码）。
2. **收银页终端分端**：同一收银地址按终端表现不同——PC 渲染二维码；手机浏览器（微信外）支付宝单给**手势主按钮「打开支付宝」**（二维码与兜底说明在按钮之前已渲染）；手机微信内支付宝单不自动跳转。
3. **微信内零点击**：在微信内打开收银页即自动完成授权并调起支付面板，买家不需要先点一次按钮。
4. **手机微信外推荐路径**：微信支付单在手机微信外给出可执行的一键引导（复制链接并打开微信 + 三步说明 + 如实兜底）。

## 不受支持（不要按这些形态设计）

- 微信**没有**「原生扫码直出付款码」：微信的 PC 扫码是**中转链**（二维码 → 手机微信内 → 页面调起）。
- 手机浏览器（微信外）**不能**直接拉起微信支付面板。
- 平台侧**没有**托管收款页形态；收款页形态只有两类：商家自渲染官方收款码、平台收银页。
- 商家自有 App **不得**用内嵌浏览器打开收银页，必须跳系统浏览器。

## 影响面与迁移动作

- **影响面**：商家 API 新增一个可选字段；收银页买家体验变化。
- **迁移动作**：**无需迁移**（路径仍在 `v1`、字段只增不改）。旧解析逻辑不受影响；若你要用官方收款码，读新字段即可，不读也不影响现有流程。
